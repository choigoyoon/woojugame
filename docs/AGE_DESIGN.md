# 우주 블록 오락실 — 연령 선택·난이도·이야기 경험 설계

2026년 11월 25일 · 제작안 v0.2 · 최초 기준 `c37adaa`, 독립 축/검증 범위 재검토 기준 `a2924fd`.

사용자 요구: **이야기를 단순하게 만들지 않고, 연령을 선택하며 연령대에 맞는 난이도와 기능을 제공한다.** 게임 70%·교육 30%, Android 60fps, 다음 날/다음 기기에서도 이어 하는 세계를 유지한다.

현재 앱에는 연령 선택이 없다. `config.js`의 공통 수치, 배틀의 최근 선택 기반 연산 단계, 러너/광장의 반복 진행은 서로 별개다. 이 문서는 **신규 기능의 설계이며 구현 완료 보고가 아니다.** 연령 구간과 수치는 제작·관찰을 위한 시작값이며 발달 검사나 교육과정 인증 기준이 아니다. 이야기의 사실·엔딩·자산은 모든 연령에 공통이고, 정보를 보여 주는 방식과 행동 부담을 달리한다.

읽는 순서: [연령 선택](#age-choice) → [연령별 경험](#age-presets) → [개별 난이도](#age-axes) → [네 모드의 실제 차이](#age-modes) → [같은 사건의 다른 경험](#age-story) → [저장·구현·검증](#age-delivery).

**재검토 판정:** 아래 연령 구간·1,000~1,800ms 예고·세 코스 후 제안 등의 수치는 검증 전 가설이다. 연령별 적합성을 확인한 제품 규격으로 인용하지 않는다. 최초 관찰은 원래 핵심 대상인 8~9세의 서로 다른 숙련/읽기 경험부터 시작하고 다른 연령에도 확대한다. 연령 선택 기능과 각 연령에 충분히 재미있는 콘텐츠를 확보했다는 주장은 구별한다. 전체 제작/검증 범위는 [PLAN의 설계 재검토](../PLAN.md#설계-재검토-아직-충분하지-않은-부분과-제작-중단-조건)를 따른다.

## A1. 공통으로 지킬 것

- 나이는 시작 설정을 고르는 정보다. 읽기 속도·조작 숙련·기억을 하나의 점수로 묶거나 같은 나이면 같은 능력이라고 판단하지 않는다.
- 모든 연령에 친구들의 목적, 단서, 반전, 선택의 결과와 완전한 엔딩을 제공한다. 낮은 연령 설정에서 줄이는 것은 동시에 처리할 정보이지 이야기의 인과관계가 아니다.
- 고급 모드는 적 HP·숙제 수만 늘리지 않는다. 다른 공략, 도구 조합, 먼저 해결할 일, 공간 배치와 창작으로 깊이를 만든다.
- 연령에 따라 파츠/코인/친구/선호 모드의 접근을 막거나 가격을 다르게 하지 않는다. 같은 사건은 어느 모드로도 해결할 수 있다.
- 네 기본 입력, 100ms 선입력, 관대한 히트박스, 0.8초 홈 안전장치, 자동 저장, 대사 스킵/다시 듣기는 공통이다. 나이가 많다고 터치 영역을 줄이지 않는다.

## A2. 연령 선택 화면과 변경 흐름

최초 실행의 짧은 설정 카드에서 **6~7세 / 8~9세 / 10~12세 / 13세 이상**을 선택한다. `나중에 정하기`도 제공한다. 생년월일·학교·이름·정확한 나이 계산을 요구하지 않는다. 선택한 숫자 구간 그대로 저장하며 한국식 나이/만 나이를 자동 변환하지 않는다. 안내는 ‘시작 설정이며 언제든 바꿀 수 있어요’ 한 줄이다. 6세 미만에 대한 별도 적합성 판단은 이 제작 범위 밖이다.

구간을 누르면 음성/그림으로 짧게 미리 보고 시작한다. 읽기 시험, 계산 시험, 연속 설정 마법사는 없다. 나중에 정하면 `ageBand: null`과 별도의 `starter` 설정을 쓰며 나이를 추정해 채우지 않는다. starter는 A0/Q0/L0/M0/P0/N0에서 시작하고 곧바로 더 깊은 플레이를 선택할 수 있다. 기존 저장의 사용자는 지금의 설정·진행을 보존한 채 로비에서 한 번만 선택을 제안한다.

보호자 센터에서 연령대와 세부 기본값을 변경한다. 나이가 바뀌는 날이나 새해에 자동으로 난도를 올리지 않는다. ‘연령 추천으로 바꾸기’는 바뀔 항목을 미리 보여 주고 수동 조정을 덮어쓸지 선택하게 한다. 나이 표시는 게임 중 이름표나 점수판에 노출하지 않는다.

아이 화면에는 연령표/여섯 개 슬라이더를 늘어놓지 않는다. 코스 출발 카드에서 **편하게 / 기본 / 도전**과 **다시 듣기·그림 보기**를 제공한다. 이 세 선택은 해당 코스의 조작/경로 변형이며, 읽기·수 범위를 함께 바꾸지 않는다. 도움을 켜거나 낮은 부담으로 바꾸는 데 PIN을 요구하지 않는다. 보호자 PIN/상점 구매/원격 백업 권한은 그대로 분리한다.

설정 이후 기존 체크포인트는 당시 규칙으로 재개한다. 새 기본값은 다음 코스 출발부터 적용한다. 당장 부담을 낮추려면 일시정지 상태에서 **‘안전 지점에서 도움 적용’**을 선택한다. 이미 받은 보상과 전달/해제한 목표는 보존하고 적용 사실을 기록한다. 설정 변경만으로 적을 부활시키거나 보상을 다시 받을 수 없다.

## A3. 연령별 시작 경험

| 연령 선택 | 시작값 A/Q/L/M/P/N | 조작·정보 제시 | 게임에서 생각할 일 | 새 기능의 기본 노출 |
| --- | --- | --- | --- | --- |
| 6~7세 | 0/0/0/0/0/0 | 위험 한 가지씩, 큰 그림과 자동 음성, 선택 전 안전 발판 | 보이는 결과를 예상하고 하나의 행동을 실행. 짧은 기억·수량을 실제 행동에 사용 | 현재 목적 그림, 보유 도구 한 개씩 소개, 요청 그림 유지 |
| 8~9세 | 1/1/1/1/1/1 | 익숙한 입력은 빠르게, 새 장치만 시범, 음성+짧은 말 | 두 유효한 방법 비교, 일부 전달, 앞에서 본 단서 다시 사용 | 두 경로 미리보기, 가방 교환, 단서 앨범, 간단한 장비 비교 |
| 10~12세 | 2/2/2/2/2/2 | 아는 장치 두 개 조합, 긴 설명은 선택 열람 | 경로/무기/운반 순서의 손익 비교, 서로 떨어진 단서 연결 | 경로 지도·장비 특성 비교·같은 조건 재도전·기록 비교 |
| 13세 이상 | 2/3/2/2/2/2 | 동일한 조작 기반에 공략과 선택 목표 강조 | 제한된 자원으로 효율적인 계획, 다른 해법 설계 | 계획 미리보기·선택 도전. 코스 제작기는 장기 확장 단계에서 제공 |

13세 이상이라고 최대 액션 단계 A3를 자동 적용하지 않는다. 8세도 액션 A2를 고르고 말 L0 지원을 유지할 수 있다. 반대로 12세도 A0·음성 지원으로 동일한 이야기를 끝낼 수 있다. 표의 기능은 콘텐츠가 실제 구현되고 필요한 도구를 만났을 때 노출한다. 미구현 제작기/새 책을 실행 가능한 버튼으로 표시하지 않는다.

연령을 높은 것으로 선택해도 새 책이 즉시 모두 열리거나 경제 보상이 증가하지 않는다. 낮은 것으로 바꿔도 기존 고급 기록·발견·친구가 지워지지 않는다. 기능을 간단히 표시하는 설정과 기능 사용 권한은 구별한다.

## A4. 여섯 축을 따로 조절한다

### A — 액션/타이밍

| 단계 | 일반 위험의 최소 읽기 예고 | 동시에 판단할 독립 위험 | 러너 기본 이동 배율 | 대표 차이 |
| --- | --- | --- | --- | --- |
| A0 | 1,800ms | 1 | 0.85 | 넓은 안전 착지, 한 번에 한 장치 |
| A1 | 1,500ms | 1 | 1.00 | 같은 입력의 다른 타이밍/경로 |
| A2 | 1,200ms | 2 | 1.00 | 이미 아는 두 장치의 순서·위치 조합 |
| A3, 선택 도전 | 1,000ms | 2 | 1.05 | 제한된 경로·정밀한 조준·다른 무기 공략 |

‘위험 2개’는 화면의 적 수가 아니라 서로 따로 읽어야 하는 공격/이동 판정 두 개다. 화면에 탈출 가능한 안전 영역이 있어야 하며 새 장치 두 개를 처음부터 동시에 소개하지 않는다. 수량/말 선택 장면과 위험 예고를 겹치지 않는다. 가독성 장면의 안전 구간이 예고 수치보다 우선한다.

계단의 **0.5초 브레이크 예고 + 2초 멈춤**은 모든 단계에서 유지한다. 위 일반 예고 표를 브레이크 값에 덮어쓰지 않는다. A0는 새 브레이크 전에 바람개비가 느려지는 사전 단서를 보여 줄 수 있지만 본 판정 규칙은 같다. 자동 상승/다리 충돌 우선순위도 유지한다.

점프 중력·길게 누르기·선입력·피격/획득 크기는 공통이다. 속도 배율별로 발판 사이 거리와 안전 착지 가능성을 검증한다. 배율만 줄여 도달 불가능한 틈을 만들지 않는다. 같은 코스·무기·보스의 HP와 화력 공식은 연령으로 바꾸지 않는다. A0를 선택했다고 총알/폭발/황금 질주의 손맛을 약하게 만들지 않는다.

### Q — 수량과 자원 판단

| 단계 | 피연산자·중간값·결과 범위 | 장면 예시 | 제공하는 단서 |
| --- | --- | --- | --- |
| Q0 | 0~5 | 병사 2명에 1명 합류, 남는 자리에 실제 입장 | 묶음 그림·손가락으로 세어지는 실제 등장, 수식은 선택 표시 |
| Q1 | 0~10 | 4명+3명 지원 대 6명+2명 지원 | 그림과 숫자, `4+3` 결과를 합류 모션으로 확인 |
| Q2 | 0~20 | `7+8` 대 `19−2`, 필요한 운반 인원과 비교 | 두 경로의 실제 효과 미리보기, 원하면 묶음 그림 |
| Q3 | 0~100 | 창고 재고와 운반 비용 비교, 보급 두 번 중 먼저 받을 곳 | 한 장면 최대 두 대안, 안전 지점에서 계획. 시간제한 암산 아님 |

덧셈/뺄셈의 표시값과 실제 합류·소비량은 일치한다. 작은 양수 경로를 선택했다고 임의로 병력을 줄이지 않는다. 차감은 실제 비용으로 사전에 표시하고 자원이 부족하면 다른 통과 가능한 길을 제공한다. 숫자 크기보다 무기의 형태·위치·소요 경로가 유리한 선택도 있어야 한다. 곱셈·분수 등 새 교과를 연령만으로 자동 추가하지 않는다.

### L — 말의 길이와 행동 연결

| 단계 | 처음 제시하는 정보 | 플레이 결과 |
| --- | --- | --- |
| L0 | 그림+자동 음성의 한 행동: ‘상자 밀어!’ | 코코가 상자를 밀어 길이 생김. 문장 조립을 기다리지 않음 |
| L1 | 누가/무엇을/어떻게 할지 그림으로 이어지는 짧은 문장 | ‘코코가 상자를 밀어’와 ‘로봇이 다리를 내려’가 서로 다른 유효 경로 |
| L2 | 이미 아는 두 행동의 순서: ‘상자를 옮긴 다음 다리를 내려’ | 먼저 실행한 장치가 다음 이동/운반 경로를 바꿈 |
| L3, 선택 도전 | 조건 한 개가 있는 계획: ‘기차가 지나가면 문을 열어’ | 장치 예고를 보고 실행. 문법 용어/오답 채점 창 없음 |

한국어 조사·명사·동사의 결합과 실제 애니메이션이 맞아야 한다. 문장 완성은 읽는 중 점프를 요구하지 않는 안전 장면에서 처리하고, 일반 액션만으로도 코인·질주·엔딩에 도달한다. 음성 OFF/TTS 미지원이면 같은 그림/짧은 글/장치 시범을 제공한다. 듣기를 켰다는 이유로 기록을 낮추지 않는다.

연령 추천의 자동 음성은 기존 전체 소리 OFF보다 우선하지 않는다. 기존 소리/진동/모션 감소 설정을 연령 변경으로 되돌리지 않는다. 오프라인 TTS 실패 시 오류 없이 합성음과 그림을 사용한다.

### M — 요청 기억과 불필요한 자극 걸러내기

| 단계 | 한 번의 요청 | 요청 그림 기본값 | 방해 정보 |
| --- | --- | --- | --- |
| M0 | 1종, 총 1~2개 | 유지 | 목표와 형태가 다른 여분 1종 |
| M1 | 2종, 총 3개 | 확인 뒤 접힘, 언제든 재확인 | 다른 색·다른 물건 중 하나만 추가 |
| M2 | 2~3종, 총 3~5개 | 출발 전 확인, 언제든 재확인 | 이미 아는 여분 + 운반 경로 선택 |
| M3, 선택 도전 | 종류/총량은 M2 범위 | 변경 요청을 정지된 안전 지점에서 확인 | 부탁 한 항목 변경 또는 배달 순서. 둘을 동시에 추가하지 않음 |

M1 이상도 그림을 계속 켜 둘 수 있다. 요청은 출발 확인 전 사라지지 않으며 다시 보기에 벌금·실패·코인 감소를 적용하지 않는다. 가방 3칸/후속 최대 5칸과 맞지 않으면 부분 전달로 해결 가능해야 한다. 목표·여분·수량 변경과 이동 위험 증가는 동시에 올리지 않는다. ‘게임기는 항상 나쁨’처럼 물건 자체를 정답/오답으로 고정하지 않는다.

### P — 계획, N — 이야기 정보의 제시

| 단계 | P: 플레이 계획 | N: 이야기 제시 |
| --- | --- | --- |
| 0 | 당장 할 일 1개. 완료 후 다음 결과를 보여 줌 | 핵심 원인→행동→결과를 같은 장면의 그림으로 연결 |
| 1 | 두 경로/도구 중 하나 선택, 결과 미리보기 | 앞 장의 단서 하나를 지금 물체 옆에 다시 보여 줌 |
| 2 | 두 하위 목표의 순서 선택, 도구/가방/거리 함께 고려 | 두세 단서의 관계를 앨범에서 살펴봄. 추가 대사는 선택 |
| 3, 선택 도전 | 같은 목표를 다른 배치로 해결하거나 작은 코스 설계 | 친구의 다른 관점·나중에 돌아온 결과를 자발적으로 탐색 |

N은 진실을 숨기는 단계가 아니다. 핵심 사건과 인물 동기는 N0에서도 행동으로 보여 준다. 앨범을 정답 순서로 정렬해야 다음 지역이 열리는 규칙은 없다. P3 제작기는 별도 후속 기능이고, 현재는 P2까지의 실제 코스가 먼저다. 연령보다 숙련·호기심에 맞춰 선택할 수 있다.

## A6. 같은 나이 안의 차이와 적응

예: 8~9세를 고른 아이가 조작은 능숙하고 글은 천천히 읽으면 **A2/Q1/L0/M1/P1/N1**, 읽기를 즐기지만 점프가 부담되면 **A0/Q2/L2/M1/P1/N2**처럼 설정한다. 연령대 변경 없이 축별 지원을 바꿀 수 있다.

첫 플레이를 몰래 시험으로 채점하지 않는다. 이미 하는 코스에서 같은 안전 구간을 두 번 어려워하면 해당 동작만 돕는 제안을 보여 준다. 제안을 거절하면 자동으로 반복 띄우지 않고 다음 코스에서 도움 버튼만 남긴다. 난도를 높이는 제안은 같은 설정의 서로 다른 코스 3개를 완료하고, 각 코스의 해당 동작이 실제로 수행된 표본이 있을 때에만 출발 카드에 최대 한 번 보여 주는 초기 규칙으로 둔다. 횟수 기준은 `config.js`에서 관리한다.

완료·실수만으로 읽기/인지 능력을 추정하지 않는다. AFK, 보조 자동 수행, 재개 직후, 같은 물건 반복 획득, 강제 종료 데이터는 숙련 상승 근거에서 제외한다. 조작 오류가 줄었다고 수량 범위를 올리지 않는다. 제안을 수락한 경우에만 한 축을 한 단계 바꾸고 다음 코스에서 적용한다. 현재 배틀의 최근 10회 선택 기반 자동 난도는 개편 코스에서 이 명시적 흐름으로 교체하며 옛 기록을 연령 판정으로 사용하지 않는다.

수동 고정과 지원 OFF를 존중한다. 새로운 연령 추천을 적용해도 사용자 지정 축은 명시적으로 선택하지 않는 한 유지한다. 쉬운 설정/그림 유지/다시 듣기 사용은 실패로 집계하지 않는다. 보호자 보고는 ‘어떤 조건에서 무엇을 했는가’를 표시하며 연령 평균과 비교한 순위나 성장 진단을 만들지 않는다.

## A7. 같은 사건의 복잡성을 다르게 경험한다

예시 사건은 공장 C2의 **빈 큰 상자·움직이는 연결 고리·역으로만 향하는 배송**이다. 핵심 진실은 모두에게 같다: 큰 상자는 무대의 빈 보호 포장이고, 마지막 칸은 보조 선로로 이동했으며, 역장 루프의 집결 계획 때문에 다른 지역의 물건까지 역으로 향한다.

아래 표는 **계획 P1을 고정하고 이야기 제시 N만 바꾼다.** 이전의 N0/P0·N2/P2 묶음 예시는 폐기한다. 쉬운 설명을 선택했다고 공략이나 선택권을 줄이지 않는다.

| 이야기 제시, 모두 P1 | 실제 플레이와 대사 | 그대로 유지하는 선택 |
| --- | --- | --- |
| N0 | 두 길의 작은 움직이는 그림, 비어 있는 상자와 연결 고리를 함께 표시. 출발/도착은 실제 물건 이동으로 보여 줌 | 큰 상자길/고리길 두 접근 중 선택. 선택의 물리 효과를 삭제하지 않음 |
| N1 | 같은 두 길에 짧은 설명과 배송표 조각의 겹침 표시. 지난 장면의 단서를 다시 제시 | N0와 같은 접근 선택. 먼저 본 단서와 현재 물체를 연결할 기회 |
| N2 | 같은 두 길, 선택 열람 가능한 출발/도착 기록과 인물의 관점 추가 | N0와 같은 접근 선택. 더 긴 설명을 읽어야 이득이 생기는 규칙은 없음 |

계획 P를 바꾸면 N과 관계없이 별도 변형을 적용한다. P0는 장치를 하나씩 해결하고, P1은 접근길 두 개 중 선택하며, P2는 발전기/운반대를 어떤 순서로 멈출지 골라 고리 위치와 적 대형을 바꾼다. **N0/P2**는 글 대신 움직이는 장치 그림 두 개로 순서와 결과를 미리 보고 같은 전략을 고른다. **N2/P0**는 깊은 단서를 살펴보면서 실제 조작은 한 장치씩 수행할 수 있다. 어느 조합에서도 핵심 진실은 같다.

공장 C2의 N0~N2 × P0~P2 **9조합**을 별도 검증 대상으로 둔다. 글을 못 읽는다는 이유로 두 유효한 해법 중 하나를 대신 선택하지 않는다. N3/P3의 관점 확장·개인 코스 제작은 후속 연구 후보로 유지하고 기본 기능의 완성 증거로 사용하지 않는다.

N0~N2는 새 코스 3개가 아니라 같은 코스의 정보·접근 변형이다. 상세 인물 동기와 12사건의 단서/결과는 [STORY S2-A](STORY.md#story-depth)에 둔다. 연령별로 정답 엔딩/나쁜 엔딩을 나누지 않는다.

## A8. 저장·코드 경계와 제작 순서

장기 저장의 L0가 선행한다. 이후 연령 선택/공통 설정과 첫 배틀 H1을 함께 연결하고, 각 모드를 개편할 때 같은 계약을 적용한다. 별도 `AGE_CONFIG`를 렌더러마다 하드코딩하지 않는다. 수치·기본값·제안 임계값은 `js/config.js`, 결정 로직은 신규 `js/difficulty.js`, 사건/문장/변형은 콘텐츠 데이터, 표시/선택은 로비·보호자 센터에 둔다. 해당 기능 구현 전 빈 런타임 파일을 만들지 않는다.

프로필의 계획 필드 예시(현재 v3 저장에 추가하지 않음):

```json
{
  "experience": {
    "version": 1,
    "ageBand": "8-9",
    "presetId": "age-8-9-v1",
    "presetVersion": 1,
    "overrides": { "action": 2, "language": 0 },
    "support": { "requestPicture": "on-demand", "speech": true },
    "suggestions": "ask"
  }
}
```

유효한 연령 값은 `null`, `6-7`, `8-9`, `10-12`, `13-plus`다. 기존 사용자는 `legacy-custom`로 기존 설정을 보존한다. 미등록 값은 프로필 전체 초기화 대신 해당 설정만 보수적인 기본값으로 복구하고 원본을 남긴다. 알 수 없는 상위 프로필/경험 버전은 LONG_TERM의 쓰기 금지·업데이트 안내를 따른다.

실행마다 `difficultySnapshot`에 여섯 축·지원·presetVersion·rulesVersion·적용 변형 ID를 기록한다. 진행 중 설정 변경은 `pendingExperience`로 보관하고 다음 실행에서 반영한다. 중간 도움 적용은 현재 보상 원장을 유지한 안전 경계에서 새 구간 스냅샷을 만들며 기록 비교에서 해당 실행의 지원 이력을 보존한다. 기본 코스/사건 첫 완료 키는 나이나 설정 ID를 포함하지 않는다.

기록 비교 키는 코스·규칙·실제 변형/난도·지원 조건을 사용하고 연령을 순위 키로 쓰지 않는다. 새해/생일/오프라인 복귀로 필드를 자동 수정하지 않는다. 설정과 완료 기록은 백업·기기 이전에 포함한다. 날짜와 연령만 바꿔 지갑이나 첫 완료 보상을 늘릴 수 없어야 한다.

제작 순서:

1. L0 저장 보호·네 모드 복원·독립 백업, 형식 이전 기반.
2. 연령 선택과 세부 기본값, 명시적 변경·안전 재개를 첫 H1/로비 세계에 연결. 미개편 모드는 설정 적용 범위를 명시하고 아직 적용되지 않은 것을 적용됐다고 표시하지 않음.
3. 항구 12코스에서 네 모드의 A/Q/L/M/P/N 소비 지점과 핵심 이야기 공통 결과 검증.
4. 공장 C2와 역 T2/T3에서 단서·선택·인물 변화가 연령별로 이해되는지 관찰하고 네 장으로 확장.
5. 새 책·고급 조합·개인 코스 제작기는 LONG_TERM의 운영 단계에 맞춰 별도 제작.
