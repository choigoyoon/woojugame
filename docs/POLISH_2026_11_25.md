# 로비·캐릭터·배틀 동작 개선 검증

2026년 11월 25일. 기준 코드 `a35f1ba`에서 실제 런타임을 수정했다. 문서에 있는 연령/스토리/장기 운영 전체를 구현한 릴리스는 아니다.

## 실제 변경

- 로비: 깊이가 있는 오락기 몸체·유리 화면·버튼, 모드마다 다른 색과 미리보기, 아바타 받침대. 기존 항구 완료 기록을 상단 배지에 반영한다.
- 공통 아바타: 호흡, 고개/시선, 눈깜빡임, 팔꿈치·무릎 관절을 분리한다. 머리 파츠는 고개에, 몸통 파츠는 몸통에 붙인다. 러너는 공중에서 발을 접으며 기존 착지 탄성과 연결한다.
- 배틀: 입력 즉시 대장이 움직이고 방향에 따라 기울며, 뒷줄만 짧게 따라온다. 걷기 캐시의 주기와 재생 주기를 일치시켰다. 대장에게 장착 파츠를 표시하고 일반 대원의 왕관·날개 반복 중첩을 줄였다.
- 모드 이동: 240ms 화면 전환 중에도 입력/물리가 바로 진행된다. 모션 감소 설정과 화면 전환/리사이즈를 처리한다.
- 배틀 규칙: 작은 양수도 해당 인원만큼 합류하고 코인을 한 번 지급한다. 첫 게이트 생성 18초, 이후 30초 간격. 세 구간에서 적 편성을 바꾸며 새 보스 HP는 600/900/1200으로 고정한다. 기존 체크포인트에 이미 등장한 보스는 저장 HP를 유지한다. 펠릿 수 증가가 총 화력 예산을 중복 증폭하지 않도록 조정했다.
- 저장 보호: 기본/백업 키의 상위 버전 감지 시 기본 프로필로 덮어쓰지 않는다. 실행 중 발견해도 중지한다. 부트가 중단된 화면에서도 대기 중인 업데이트를 적용할 수 있다. 후보 검증을 마친 뒤 데이터 전체를 교체하며 시간/횟수 상한은 코인과 분리했다.

## 시각 검수

`python3 tests/visual_audit.py`에서 실제 제품 렌더러로 63장(12장면 + 유료 파츠 9종 × 휴대폰/폴드/태블릿), 최대 코인 표시 12장, 전체 뷰포트 3장을 생성했다. 78장의 화면을 모음 이미지로 모두 열어 비교했고 로비·배틀·로켓 팩은 원본 이미지로도 확인했다. 플레이 증거와 분리한 결정적 렌더링 fixture다.

검수 중 발견해 수정한 사항:

1. 로비 점프 미리보기에서 머리/왕관이 잘리는 문제: 크기와 점프 높이, 상단 아바타 위치 조정 후 재촬영.
2. 로켓 팩이 팔 뒤에 숨는 문제: 탱크/분사구의 위치와 폭 조정 후 아홉 파츠 재촬영.
3. 대규모 부대의 왕관·날개 중첩: 대장과 일반 대원의 실루엣을 구분한 후 재촬영.
4. 기존 시각 fixture가 직접 장착 필드를 바꾸어 캐시된 팔레트를 재사용하던 문제: 실제 `equip` 경로로 바꾸어 각 파츠가 서로 다른 모습으로 촬영되는지 확인.

표본 화면에서 새로운 잘림/레이아웃 이탈을 발견하지 않았다. 임의의 모든 조합·모든 애니메이션 프레임에서 1픽셀 오차가 없다는 보장은 아니다. 러너 상단의 문장 슬롯, 광장 지시 패널과 반복 구조는 아직 개편 전이다.

## 기능·저장·오디오 검증

- `npm test`: 100개 통과. 양수 문/음수 문, 단일 지급, 고정 보스 HP, 부대 증가에 따른 동일 보스 처치 시간 감소, 기존 보스 복원, 상위 저장 보호와 10년 합성 시간 보존을 포함한다. 기존 4시간 시뮬레이션과 240회 재시작 검사는 자동 모델 검사다.
- `python3 tests/campaign_browser_check.py`: 실제 터치로 하늘 항구 3라운드 완료, 전투/결과 재접속, 무기 선택, 최초 보상, 완료 배지, 18개 결과 화면/뷰포트 조합 통과. 게임 시간은 125.44초 / 144.04초 / 156.62초. 제어된 테스트 시계이며 Android 실측 시간이 아니다.

- `python3 tests/pwa_check.py`: `/woojugame/` 경로, 36개 캐시 자산, 전체 브라우저 종료 후 오프라인 재실행, 코인·파츠 복원, 손상된 기본 저장 복구, 실패한 업데이트 보류와 명시적 업데이트 통과. Chromium 설치 가능성 검사 오류 0. 실제 Android 설치/비행기 모드는 별도다.
- `python3 tests/audio_audit.py` / `audio_plot.py`: 실제 Float32 출력 30사례 통과. RMS/Peak·유한 샘플·배경 음소거·과부하·모드 전환 검사와 WAV/파형 생성. 안전 파형 그림을 열어 확인했다. 이번 변경에서 작곡/효과음 엔진을 새로 만들지는 않았고 실제 휴대폰 스피커 청취는 하지 않았다.

## 재생 자료와 남은 범위

`python3 tests/record_preview.py`는 새 프로필로 로비 → 드래그 배틀 → 점프 러너 → 로비를 실제 시간/터치로 녹화한다. `test-results/arcade/motion-preview/arcade-motion.webm`과 MP4 변환본은 25fps 무음 녹화이며 게임의 60fps 측정 자료가 아니다. 녹화 프레임 모음으로 실제 합류·사격·점프 장면을 확인했다. 테스트 결과물은 `test-results/`에 생성하며 저장소에는 검사 코드와 이 기록을 남긴다.

이 변경은 로비·아바타 동작·배틀 규칙의 개선이다. 연결 스토리, 연령 선택, 세계 변화, 러너/광장 구조 개편, 계단 이어하기, 세대별 저장/독립 백업은 미완료다. 실제 Android 장시간 발열/터치, 8세 사용자 재방문·재미·학습 효과 검증도 남아 있다. 배포 방식은 main 루트 GitHub Pages 직접 서빙, Actions는 검증이다.
