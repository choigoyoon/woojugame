# 0.4 네 모드 통합 검증 기록

검증일: 2026년 11월 20일. 기반 커밋 `d6645f7`. Node.js 24.22.1, Python Playwright 1.62.0, Linux Chromium 156.0.8078.79. 실제 Android 기기에서 측정한 기록은 아니다.

## 구현 범위

- 로비·계단·하늘 항구 배틀의 공통 시간/입력/저장/풀링 재정비.
- 러너 24문장, 가변 점프·착지 선입력·헤딩·5초 황금 질주.
- 광장 쿼터뷰·플로팅 조이스틱·목표/유혹·이동 방해·배달·단계별 목표 증가.
- 구매 파츠 9종, 네 게임의 실시간 장착 렌더링, 전설 코인+PIN 이중 해금.
- 곱셈 보호자 게이트, PIN 확인/변경/해시/재시도 제한, 설정과 누적 지표.
- v3 프로필 이전·백업, 배틀/러너/광장 체크포인트, PWA 설치용 manifest·자체 Canvas 아이콘·버전 캐시.

별도 구역 8개를 모두 제작하거나 실제 결제/클라우드 계정/서버 인증을 추가한 버전은 아니다. 휴식 쿨다운 정책도 이번 요청 범위 밖이다.

## 자동 규칙 검증

`npm test`: **67개 통과, 실패 0개**.

- 60/90/120Hz에 같은 입력을 공급해 배틀 이동·발사·격파·보상·시간, 러너 전체 상태, 광장 전체 상태의 동등성 확인. 키보드 이동도 고정 틱 안에서 처리.
- 프레임 50ms 클램프, 5ms 물리 틱 나머지 누적, 타임스탬프 역행 방어.
- 100ms 입력 버퍼 경계, 휘청 회복 순서, 착지 선입력, 일시정지 시 큐 폐기, 빨간 브레이크 즉시 판정.
- 85% 유해/120% 획득 판정, 유리한 게이트 경계, 러너 헤딩의 이전/현재 위치 교차.
- 풀 객체의 참조가 유지되는지 확인. 러너 20분 반복과 광장 20회 배달에서도 풀 용량과 코인 일치.
- 배틀 자동 저장이 프레임 중간의 미처리 틱을 포함하지 않는지, 정상 종료 없이 저장 시점에서 재구성해도 체크포인트가 유효한지 확인.
- v1/v2→v3 이전, 백업 복원, 보유 파츠/설정 유지, 특정 모드 손상 격리, 필요한 물건이 사라진 광장 데이터/잘못된 러너 슬롯 복구.
- PIN 변경 해시·이전 번호 거부·5회 오류 대기, 코인+PIN 둘 다 확인, 중복 구매 차감 방지.
- 진동 미지원·설정 OFF·호출 빈도 제한, 소리 음원 상한, 계단·브레이크·그림 다리·배틀 회귀.
- 보호자 통계에서 방치 통과, 결과/출동 대기 시간, 노란 예고 중 방향 실수를 별도로 처리.
- 서비스 워커의 버전 해시와 배포 파일 전체가 일치하는지 검사.

기존 4시간 배틀 규칙 시뮬레이션도 통과했다. **101라운드, 재실행 240회**, 첫 클리어 보너스 200코인 1회 한정, 최종 22,686코인, 최대 저장 크기 10,848바이트. GPU를 4시간 렌더링한 결과나 4시간의 독립 콘텐츠 분량이 아니다. 하늘 항구의 이번 규칙 시뮬레이션 시간은 125.8 / 142.0 / 154.0초였다.

## 브라우저 터치·화면·수명주기

`python3 tests/production_browser_check.py`: **통과, JS 오류/HTTP 실패 0건**.

시험 시작 시 과거 v2 지갑에 3,500코인이 있는 조건만 주입했다. 이후 구매와 플레이에는 실제 브라우저 터치 입력을 사용하며 게임 상태나 보상 함수를 직접 수정하지 않았다.

- 곱셈 답 → 보호자 창 → PIN 2회 입력으로 변경 → 초기 번호 거부 → 새 번호로 전설 파츠 구매 → 같은 파츠 재선택 시 차감 없음.
- 머리 왕관·몸통 갑옷·등 로켓 팩 장착 후 네 게임과 로비/상점에 반영.
- 세 낱말을 실제 길게 누르는 점프로 헤딩, 문장 완성·황금 질주·45코인 지급. 재실행 후 문장 진행과 코인 보존.
- 터치 원점 기준 조이스틱으로 유혹 물건을 피해 목표만 수거하고 대장에게 복귀, 50코인 지급.
- 계단/배틀/러너/광장/상점/보호자 6화면 × 6비율 = **36개 조합**. 360×800, 412×915, 344×882, 768×1024, 1024×1366, 915×412에서 중앙 9:16과 조작부 안전 영역 확인.
- `pagehide/pageshow`, `visibilitychange`, focus/blur 핸들러를 해당 플랫폼 상태와 함께 검사. 숨겨진 시간에는 모드 타이머가 진행하지 않으며 복귀·크기 변경 시 눌린 입력을 초기화한다. 헤드리스 브라우저의 focus 에뮬레이션 때문에 실제 OS 앱 전환은 수동 항목으로 남긴다.

`python3 tests/browser_check.py --stress-seconds 60` 기존 흐름 회귀도 통과했다. 일반 화면 18개 조합, 두 손가락 입력과 드래그 소유권, 브레이크/네 그림 다리, 수식 오답/정답과 보스·무기 선택, 기본 경로와 단일 HTML 실행을 확인했다.

## PWA·오프라인·업데이트

`python3 tests/pwa_check.py`: **통과, 오류 0건**.

- 기존 0.3의 호환되지 않는 모듈이 HTTP 캐시에 아직 유효하게 남아 있는 조건을 재현했다. 첫 PWA 부팅이 네트워크에서 새 셸을 완성하고 제어권을 확보한 뒤 모듈을 열어 혼합 버전 실행을 방지했다.
- `/woojugame/` 프로젝트 경로에서 31개 앱 셸 파일 설치. 192/512/maskable 아이콘 크기와 manifest의 scope/start URL 확인.
- Chromium 설치 가능성 검사: **installabilityErrors = []**.
- 브라우저 프로세스를 완전히 종료하고 동일 프로필을 네트워크 차단 상태로 다시 시작. 네 모드 실행, 코인·장착 파츠·러너 체크포인트 복원.
- 오프라인 상태에서 기본 저장 문서를 손상시킨 후 백업에서 복원.
- 필수 파일 하나가 없는 새 서비스 워커는 설치 실패하고 기존 캐시를 보존.
- 완전한 새 버전은 대기 상태를 유지. `저장하고 다시 열기`를 누른 뒤 전환하고 코인을 보존하며 해당 경로의 옛 캐시만 제거.

프로덕션 저장소를 바꾸지 않도록 업데이트 실패/성공 실험은 임시 복사 배포 폴더에서 수행했다. 보고서: `test-results/arcade/pwa-report.json`.
