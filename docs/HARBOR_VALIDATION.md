# 하늘 항구 0.3 검증 기록

검증일: 2026년 11월 20일. 기반 커밋: `c796577`. 환경: Node.js 24.22.1, Chromium 156.0.8078.79, Python Playwright, Linux. Android 실기기 검증 결과는 아니다.

## 구현된 제품 범위

배틀의 하늘 항구 3라운드, 무기 선택/강화, 서로 다른 예고 공격을 가진 세 보스, 첫 클리어 보너스와 배지, 진행 체크포인트, v1→v2 지갑 이전을 구현했다. 계단과 공통 로비는 연결을 유지한다. 다른 구역·모드 3/4·구매 상점·PWA는 후속 범위다.

콘텐츠와 안정성 검증은 구분한다. 현재 한 구역의 전투 분량은 약 7분이며, 2~4시간 분량의 새 콘텐츠 또는 유료 출시 준비를 완료했다는 의미가 아니다. 아래 4시간 검사는 같은 구역을 반복하는 규칙 모델의 안정성 검사다.

## 규칙·저장 검증

`npm test`: 49개 통과.

- 기존 계단·브레이크·그림 다리·배틀 타격 판정 회귀.
- 기존 지갑의 코인·기본 장착 유지, 저장 실패 시 메모리 플레이.
- 전투 중 적/탄/게이트/생성 일정/난수 시드/코인 복원과 복원 전후 동일한 전투 결과.
- 파괴된 적과 지급 코인을 같은 문서로 저장해 재실행 후 중복 지급 방지.
- 잘못된 적 목록·타이머·부대 수·연산 난이도·난수 시드의 체크포인트 격리. 해당 라운드를 재시작하고 지갑과 무기 해금 유지.
- 최근 10개 표본의 승급/유지/완화 경계, 단계별 수식 3,000쌍의 계산·범위·최소 차이. 입력 없는 통과와 급격한 차선 변경은 표본에서 제외.
- 관통탄이 앞뒤 두 표적에 각각 한 번 맞고, 연쇄포가 가까운 표적 하나에만 추가 피해를 주는 실제 충돌 검사.
- 세 라운드 완주·명시적 무기 선택·강화/해금 보존·중복 클리어 호출·첫 보너스 1회 지급·배지·재도전.
- 마지막 보스의 중앙/차선 판정, 안전한 가장자리, 복귀 시 예고 재시작.

결정적 시뮬레이션의 전투+보스+클리어 연출 시간은 각각 **125.6 / 141.9 / 153.9초**였다. 합계 **421.4초(약 7분 1초)**. 선택 화면에서 머무는 시간은 포함하지 않는다.

## 4시간 규칙 시뮬레이션

실행: `node --test tests/campaign.test.js`.

4시간 동안 101라운드를 완료하고 매 분 저장·새 프로필 생성·전투 복원을 수행했다. 재실행 240회 모두 체크포인트 복원에 성공했고, 정상 지갑과 전투의 누적 획득 코인이 일치했다. 첫 보너스는 40+60+100=200코인만 지급됐고 반복 지급되지 않았다. 지갑 22,626코인, 직렬화된 저장 데이터 약 11KB였다.

적 ≤12, 탄 ≤100, 게이트 ≤2, 부대 ≥1, 난이도 표본 ≤10을 매 단계 확인했다. 게임 상태 검사이며 GPU 렌더링·발열·배터리를 4시간 측정한 결과는 아니다.

## 브라우저 검증

실제 `/woojugame/` HTTP에서 15개 ES 모듈과 단일 파일 빌드가 동작했다. 공통 기능과 로비·계단·배틀의 18개 화면/비율 조합, 수식 게이트, 보스 지급, 명시적 무기 선택, 계단 이벤트, 실제 origin의 재실행 복원을 확인했다.

1분 실제 시간 연속 드래그: **60.11초, 입력 541회(9회/초), 평균 59.8fps, 오류 0건**. 해당 구간의 최대 적 4·탄 45·파편 160·음원 12·화면 부대원 24개. 첫 라운드 전반의 측정이며 모든 기기·모든 전투 구간의 성능 보장은 아니다.

`npm run test:campaign`: 실제 HTTP와 브라우저 터치 입력으로 세 라운드 완주, 오류 0건. 기능 검사는 제어된 게임 시계를 사용했다.

| 라운드 | 전투·보스·클리어 시간 | 사용 무기 | 획득 코인(첫 보너스 포함) |
| --- | --- | --- | --- |
| 1-1 | 125.54초 | 기본 연사 | 276(40) |
| 1-2 | 141.86초 | 관통포 | 288(60) |
| 1-3 | 153.97초 | 연쇄포 | 345(100) |

합계 421.37초. 전투 31초 시점과 매 결과 화면에서 홈 이동·페이지 재실행 후 코인·적·탄·전투 시간·선택 대기가 보존됐다. 두 번의 무기 선택, 마지막 보스 중앙/차선 회피, 항구 배지, 재도전 시 무기 해금 유지까지 확인했다. 결과 화면 3종 × 6개 비율의 추가 18개 조합을 포함해 총 36개 화면/비율 조합에서 중앙 9:16 화면과 조작부 안전 영역을 확인했다.

완주 결과는 `test-results/arcade/campaign-report.json`, 선택·보스·배지 화면은 같은 폴더의 `campaign-*.png`에 기록한다. 1분 실제 시간 성능 측정은 `browser-report.json`으로 별도 구분한다.

`python3 tests/battle_impact_check.py` 회귀 검사도 통과했다. 배럴 균열·연쇄 폭발·보급품·폭주 연사·움직임 줄이기 전환·보스 예고/회피/격노/격파·백그라운드 정지를 재확인했다. 충돌 연출 434회, 오류 0건이며 결과는 `battle-impact-report.json`에 보관한다.
