# 우주 블록 런 Phase 1 검증 기록

검증일: 2026년 11월 20일. 대상은 준비 단계와 Phase 1 계단 액션이다. 브레이크·퍼즐·상점·PIN·저장·쿨다운·PWA는 설정값과 예약 상태만 있으며 실행 기능은 포함하지 않는다.

## 실행 결과물

- 개발 실행: 저장소 루트에서 `npm run dev`. Node.js 20 이상이며 런타임 패키지 설치는 필요하지 않다.
- 단일 파일 생성: `npm run build`로 `dist/index.html`을 만든다. CSS와 JavaScript를 모두 포함하며 외부 이미지·음원·라이브러리를 불러오지 않는다.
- 상세 실행 방법: [README](../README.md).

## 자동 검증 결과

환경은 Linux, Node.js 24.22.1, Chromium 156.0.8078.79, Python Playwright 1.62.0이다. 브라우저 검증은 단일 HTML을 메모리에 로드하고 터치와 모바일 뷰포트를 에뮬레이션했다.

| 검증 | 결과 |
| --- | --- |

### 연출 장면 검증

`npm run test:visual`은 브라우저 시간을 제어하고 실제 터치 입력으로 장면을 만든다. 게임 상태를 직접 수정하지 않는다. 다음 검사와 Canvas 캡처 9장을 확인했다.

- 머리·몸통·팔·다리의 입체 명암, 점프 시 관절 회전과 스트레치, 착지 압축과 무릎 굽힘, 바닥 그림자.
- 대기 중 깜빡임과 다시 눈을 뜨는 동작, 일반 미소·10콤보 별 눈·실수 시 소용돌이 눈 전환.
- 누른 버튼의 하강, 실제 터치 좌표의 파동, 착지 직후 몸과 발판의 압축, 시간이 지나면 제자리로 수렴.
- 10콤보에서 정확히 15코인, 블록 파편과 오라 발생, 오라 종료 후에도 별 눈 유지.
- 실제 입력으로 80계단 성층권·200계단 우주 색상에 도달, 구름·별·행성 배경과 버튼 가독성 확인.
- 실행 도중 동작 줄이기 설정 변경을 반영하며 입력·보상은 유지.

결과와 캡처: `test-results/visual/report.json`, `test-results/visual/01-idle.png`부터 `09-reduced-motion.png`까지. 브라우저 JavaScript 오류는 없었다. 합성 음계의 주파수와 오디오 활성화는 자동 검증했으며, 휴대폰 스피커에서의 음량·음색은 실기기 확인이 필요하다.

### 3분 연속 터치

최종 구현에서 `python3 tests/browser_check.py --stress-seconds 180`을 실행했다.

- 실행 시간 180.03초, 실제 브라우저 터치 이벤트 총 1,406회. 목표 초당 8회, 측정 평균 약 7.81회다.
- 입력 1,406회 수집·처리, 누락·중복·의도하지 않은 차단 0회.
- 923계단과 1,383코인으로 계산 결과 일치: `923 + 92 × 5`.
- 발판 객체 16개 유지. 관찰 최대값: 파편 96개, 동시 음원 10개, 발판 반동 5개, 터치 파동 6개. 각각 정해진 상한을 넘지 않았다.
- 평균 렌더링 59.9fps, JavaScript 오류 0건, 외부 네트워크 요청 0건, 화면 확대 없음.

위 프레임 수치는 이 Linux 에뮬레이션 환경의 측정값이다. 메모리에 HTML을 넣은 실행의 준비 시점은 약 100ms였으며, 휴대폰의 최초 HTTP 로드나 1초 진입 목표를 검증한 수치는 아니다. 난수로 계단 방향을 생성하므로 반복 실행의 계단 수는 달라질 수 있고, 입력 수와 보상 공식의 일치 여부를 검사한다. 테스트 도구의 반복 좌표 조회 비용이 입력 속도에 섞이지 않도록, 이후 고정된 뷰포트의 좌표를 재사용하도록 개선했다. 실제 전송 속도는 결과 JSON의 `inputsPerSecond`에 따로 기록한다.

### 초당 9회 추가 검증

좌표 조회를 개선한 도구로 `python3 tests/browser_check.py --stress-seconds 60 --stress-hz 9`를 실행했다. 60초 동안 540회, 측정 속도도 초당 9회였으며 모두 한 번씩 처리됐다. 350계단·525코인으로 보상이 일치했고, 평균 59.8fps, 오류·외부 요청·줌·예상 밖 입력 차단은 0건이었다. 관찰 최대값은 파편 96개, 음원 7개, 발판 반동 4개, 터치 파동 4개였다. 이 검증에서도 화면 비율 6종, 동시 두 손 입력과 화면 복귀 검사가 통과했다.

브라우저 결과 JSON과 캡처는 재실행 시 `test-results/`에 생성된다. 테스트 명령과 의존성 준비 방법은 [README](../README.md)를 따른다.

- [ ] 아이가 설명 없이 두 버튼과 방향을 이해하는지 관찰한다.

공유 클라우드 미리보기는 릴레이 연결 시간 초과와 브라우저 시작 오류로 열리지 않았다. 실기기 확인용 배포는 GitHub Pages의 `main` 브랜치 루트 직접 서빙 방식으로 준비했으며, 활성화 절차는 [README](../README.md)를 따른다. `/woojugame/` 하위 경로에서 진입 HTML·CSS·6개 ES 모듈의 HTTP 200 응답을 임시 정적 서버로 확인했다. 현재 코인·진행도는 메모리에서만 유지되므로 새로고침하면 초기화된다.
