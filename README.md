# 우주 블록 런 (Uju Block Run)

## 현재 실행 버전과 실행 방법

`PLAN.md`의 준비 단계와 Phase 1 계단 액션을 구현했다. 시작 메뉴 없이 두 버튼으로 플레이하며, 일반 계단당 1코인과 10콤보마다 보너스 5코인을 얻는다. 방향 실수 시 1초간 휘청하고 콤보만 초기화된다.

**Node.js 20 이상**에서 별도 패키지 설치 없이 실행한다.

```sh
npm run dev
```

컴퓨터에서는 터미널에 표시된 `http://localhost:3000`을 연다. 같은 와이파이에 연결된 휴대폰에서는 `http://컴퓨터의-LAN-IP:3000`을 연다. 휴대폰의 `localhost`는 휴대폰 자신을 가리키므로 컴퓨터 IP를 사용해야 한다. 포트 변경은 `npm run dev -- --port 3001`로 할 수 있다. 클라우드 환경은 같은 와이파이 방식 대신 지원되는 포트 미리보기 주소가 필요하다.

왼쪽 버튼은 방향 전환, 오른쪽 버튼은 오르기다. 컴퓨터에서는 `←` 또는 `Z`로 방향을 바꾸고, `↑`·`→`·`X`·`Space`로 오른다. 화면을 벗어나면 진행과 소리가 일시정지되고 복귀하면 이어진다.

### GitHub Pages에서 휴대폰으로 실행

배포 방식은 **`main` 브랜치의 루트 파일 직접 서빙**이다. 루트의 `index.html`, `css/`, `js/`를 그대로 제공하며, `.nojekyll`로 Jekyll 처리를 끈다. 별도의 Actions 빌드·배포 워크플로우나 `npm run build`, `dist/` 업로드는 필요하지 않다.

처음 한 번 [저장소 Pages 설정](https://github.com/choigoyoon/woojugame/settings/pages)에서 다음과 같이 지정한다.

1. **Build and deployment → Source → Deploy from a branch**를 선택한다.
2. **Branch → main**, 폴더는 **/ (root)**를 선택하고 **Save**를 누른다.
3. GitHub Pages 배포가 완료되면 휴대폰에서 **[우주 블록 런 실행](https://choigoyoon.github.io/woojugame/)**을 연다.

설정 후에는 `main`에 새 커밋을 푸시할 때마다 GitHub Pages가 다시 배포한다. 배포 완료를 확인하고 페이지를 새로고침하면 새 버전을 실행할 수 있다. Source를 `GitHub Actions`로 선택하지 않는다. GitHub가 내부적으로 실행하는 Pages 배포 작업은 저장소의 Actions 탭에 표시될 수 있다.

파일 경로는 HTML의 `./css/style.css`, `./js/main.js`와 모듈 내부의 `./config.js` 등 상대 경로를 사용하므로 `/woojugame/` 아래에서도 동작한다. `dist/`와 `test-results/`는 생성 결과물로 Git에서 제외한다. 로컬 개발 서버는 `/`에서 실행하고, GitHub Pages는 `/woojugame/`에서 실행한다.

이 배포는 Phase 1 실기기 확인용 일반 웹 게임이다. PWA 설치·오프라인 캐시·진행도 저장은 후속 단계이며, 현재는 새로고침하면 코인과 진행도가 초기화된다.

### 단일 HTML 실행 파일

```sh
npm run build
```

`dist/index.html`에 CSS와 모든 JavaScript를 포함한 단일 실행 파일을 생성한다. 이 파일은 외부 이미지·음원·라이브러리를 요청하지 않는다. 파일 열기를 지원하는 브라우저에서 직접 열거나 HTML 미리보기로 실행할 수 있다. Android 파일 앱이나 브라우저가 로컬 HTML 실행을 제한하면 위 HTTP 실행 방법을 사용한다. 소스의 `index.html`은 ES 모듈을 불러오므로 HTTP 서버로 실행한다.

### 구현 범위와 검증

- 구현: 9:16 화면 맞춤, 최소 48px 안전 여백, 하단 22% 두 버튼, 양손 터치, 코인·콤보, 합성 효과음, 일시정지·복귀.
- 캐릭터: 입체 머리·몸통과 관절이 분리된 팔다리, 바닥 그림자, 숨쉬기·눈 깜빡임, 점프 시 팔다리 교차와 늘어남, 착지 시 무릎 굽힘·압축·반동. 평소 미소 → 10콤보 이상 별 눈 → 실수 시 소용돌이 눈으로 전환한다.
- 공간과 손맛: 패럴랙스 구름과 고도별 하늘 → 성층권(80계단) → 우주(200계단), 돌기가 있는 두꺼운 발판과 착지 반동, 탄성 캡슐 버튼과 터치 위치의 파동, 10콤보마다 블록 폭죽·오라.
- 소리: 480ms 안에 이어 오르면 도–레–미–파–솔–라–시–도 음계가 한 옥타브 안에서 상승한다. 잠시 멈추거나 실수·화면 이탈 후에는 첫 음부터 시작한다. 착지음과 콤보 아르페지오도 합성한다.
- 점프 연출은 다음 입력을 막지 않으며, 연타 시 현재 보이는 위치에서 다음 발판으로 즉시 이어진다. 기기의 동작 줄이기 설정을 반영한다. 주요 연출 강도·시간·음계·고도 경계는 `js/config.js`에서 조정한다.
- Phase 2·3은 `js/config.js`의 비활성 설정과 `js/game.js`의 예약 상태만 둔다. 브레이크·퍼즐·상점·PIN·저장·쿨다운·PWA는 아직 실행되지 않는다. 새로고침하면 현재 코인과 진행도는 초기화된다.
- 규칙과 HTTP 실행 검증: `npm test`.
- 브라우저 자동 검증: Python Playwright와 Chromium을 준비한 뒤 `npm run test:browser`. 기본 검증 후 연속 3분 검증은 `python3 tests/browser_check.py --stress-seconds 180`으로 실행한다.
- 입력 빈도를 높이려면 `python3 tests/browser_check.py --stress-seconds 60 --stress-hz 9`로 초당 9회를 요청한다. 실제 전송 빈도는 결과 JSON의 `inputsPerSecond`에서 확인한다.
- 연출 자동 검증: `npm run test:visual`. 브라우저 시간을 제어하며 실제 터치로 점프·착지·눈 깜빡임·10콤보·휘청임·80/200계단·동작 줄이기를 검사한다. 장면별 캡처와 결과는 `test-results/visual/`에 생성한다.

```sh
python3 -m pip install -r requirements-browser.txt
python3 -m playwright install chromium
npm run test:browser
```

설치된 Chromium을 쓰려면 `CHROMIUM_PATH`에 실행 파일 경로를 지정할 수 있다. 브라우저 검증은 단일 HTML을 메모리에 로드해 모바일 크기와 터치를 에뮬레이션하며, 실제 안드로이드 성능이나 홈 버튼 동작을 인증하지 않는다. 검증 결과는 `test-results/browser-report.json`, 화면 캡처는 같은 폴더에 저장된다. 세부 결과와 실기기 미확인 항목은 [Phase 1 검증 기록](docs/PHASE1_VALIDATION.md)에 정리한다.

## 1. 프로젝트 개요 및 타깃 유저 특성
* **타깃 유저:** 8세 남아 (글자 읽기보다 직관적 조작 선호, 즉각적인 시청각 타격감 필요)
* **유저 행동 특성 반영 (핵심 설계 기준):**
  1. **초고속 진입:** 대기 시간이나 긴 설명이 있으면 즉시 이탈함 → 실행 후 1초 내 본 게임 진입, 텍스트 설명 0%
  2. **강렬한 피드백:** 조작 즉시 화면 흔들림(Screen Shake), 블록 파편, 찰진 효과음이 터져야 몰입 유지
  3. **좌절 방지(No Game-Over):** 실수 시 처음부터 다시 시작하게 하면 흥미를 잃거나 짜증이 폭발함 → 죽어서 초기화되는 대신 '제자리 삐끗(1초 딜레이)' 처리 후 즉시 이어하기 구조 채택
* **비주얼 콘셉트:** 로블록스(Roblox) 감성의 각진 3D풍 블록 캐릭터와 하늘/용암 점프맵(Obby)

## 2. 안드로이드 전 기종 호환 및 배포 규격 (기술 명세)
안드로이드 스마트폰(바형, 폴드형) 및 태블릿의 모든 해상도와 화면 비율에 완벽히 대응한다.

| 항목 | 구현 규격 | 목적 |
| :--- | :--- | :--- |
| **해상도 스케일링** | 기준 해상도 **720×1280 (9:16 세로형)** 고정 후 기기 화면에 맞춰 자동 비율 스케일링 (`Scale.FIT` + 중앙 정렬). 남는 좌우/상하 여백은 어두운 블록 패턴 처리 | 폴드 펼침 화면이나 태블릿에서도 계단 간격 및 버튼 비율 깨짐 원천 차단 |
| **안전 영역(Safe Area)** | 상단 펀치홀 카메라 및 하단 안드로이드 제스처 바 간섭 방지를 위해 `env(safe-area-inset-*)` 및 상하단 최소 `48px` 여백 강제 확보 | 버튼 연타 중 홈 화면으로 튕기는 오작동 방지 |
| **터치 최적화** | `touch-action: none`, `user-select: none`, `-webkit-touch-callout: none` 전역 적용. 멀티터치 꼬임 방지 | 연타 시 화면 확대(줌), 텍스트 선택 팝업, 컨텍스트 메뉴 완전 차단 |
| **설치 및 배포** | **GitHub Pages** 호스팅 + **PWA (`manifest.json`, Service Worker)** 전체 화면 모드(`fullscreen`, `portrait` 고정). 데이터는 `localStorage` 자동 저장 | 앱스토어 심사 없이 안드로이드 바탕화면에 네이티브 앱처럼 설치 및 오프라인 실행 |

## 3. 핵심 게임 루프 (3단계 플레이 구조)

### Step 1. [코어 액션] 블록 계단 오르기 + '상황 신호 브레이크'
* **조작:** 화면 하단 좌측 `[방향 전환]` 대형 버튼, 우측 `[오르기]` 대형 버튼 (아이콘만 표시)
* **기본 액션:** 무한의 계단 방식으로 블록 발판을 연속으로 오르며 코인 획득 + 콤보 이펙트
* **브레이크 기믹 (주변 신호 인지 및 멈추기):**
  * 15~25계단마다 랜덤하게 배경 테두리가 노란색→빨간색으로 점멸하며 상단에 **호루라기 소리 + `[선생님/정지 블록 아이콘]`** 2초간 등장
  * **성공 (2초간 터치 멈춤):** 손가락을 멈추고 기다리면 `"SUPER STOP!"` 연출과 함께 보너스 코인 15개 폭발 + 슈퍼 점프(5계단 자동 상승)
  * **실패 (무시하고 버튼 연타):** 캐릭터가 미끄러지며 별이 도는 어지러움 모션 1초 재생 (계단 초기화 없음, 바로 이어서 진행)

### Step 2. [보너스 퍼즐] 용암 위 끊어진 다리 잇기 (상황-행동 연결)
* **발동 조건:** 매 50계단 도달 시 용암 위 끊어진 다리 이벤트 진입 (시간제한 없음)
* **진행 방식:**
  * 상단에 **`[상황 그림 카드]`** 1장 제시 + Web Speech API(TTS)로 짧은 상황 음성 출력
  * 하단에 **`[다음 행동 그림 카드]`** 보기 2개 제시 (글자 없이 큰 이모지/블록 일러스트 조합)
  * **기본 상황 데이터셋 (확장 가능 구조):**
    1. `[선생님이 칠판 앞에 계심]` → (정답) `[책을 덮고 앞을 봄]` / (오답) `[만화책을 펼침]`
    2. `[수업 종이 울림]` → (정답) `[자리에 바르게 앉음]` / (오답) `[복도로 뛰어감]`
    3. `[비가 주룩주룩 내림]` → (정답) `[우산을 씀]` / (오답) `[선풍기를 켬]`
    4. `[친구가 넘어져 울고 있음]` → (정답) `[손을 잡아 일으켜 줌]` / (오답) `[모른 척 지나감]`
* **보상:** 정답 터치 시 블록 다리가 '철컥' 조립되며 건너편 대박 보물상자 획득. 오답 터치 시 카드가 흔들리며 다시 고를 기회 부여

### Step 3. [보상 & 현실 연결] 아바타 파츠 상점 + '아빠의 암호'
* **로블록스풍 커스터마이징:** 머리(왕관, 우주 헬멧, 공룡 모자), 몸통(황금 갑옷, 히어로 슈트), 등(제트팩, 드래곤 날개, 레이저 검) 파츠 분리 장착 시스템
* **이중 해금 구조:**
  * **일반 파츠:** 게임 내 획득 코인으로 즉시 구매 및 장착
  * **전설(Legendary) 파츠:** 코인 조건 외에 **`[열쇠 잠금]`** 표시. 아이가 현실에서 아빠에게 오늘 있었던 일을 **한 문장(`[누가/언제] + [무엇을 했다]`)으로 정리해 말하기** 미션을 통과하면, 아빠가 상점 우측 상단 숨겨진 설정 아이콘을 길게 눌러(2초 롱프레스) **4자리 PIN(기본값: `0808`)**을 입력해 해금 승인

## 4. 자연스러운 종료 유도 (쿨다운 시스템)
* 누적 플레이 시간이 **15분**을 경과하면 배경 테마가 `낮(청량함)` → `노을` → `밤하늘(차분함)`로 서서히 전환되며, 효과음 톤과 BGM 템포가 부드럽고 잔잔하게 낮아져 과열된 흥분을 자연스럽게 가라앉힌다.

## 5. 폴더 구조 (권장)
```text
uju-block-run/
├── index.html          # 뷰포트, Safe-area, 풀스크린 메타태그 설정
├── manifest.json       # 안드로이드 홈 화면 앱 설치용 PWA 매니페스트
├── sw.js               # 오프라인 실행용 서비스 워커
├── css/
│   └── style.css       # 터치 방지, 9:16 레터박스 및 반응형 레이아웃
└── js/
    ├── main.js         # 게임 초기화, 해상도 스케일러, 상태 관리
    ├── renderer.js     # 로블록스풍 2.5D 블록 캐릭터 및 파츠 Canvas 렌더링
    ├── audio.js        # Web Audio API 기반 프로시저럴 효과음 & TTS
    ├── scenarios.js    # 끊어진 다리(상황-행동 연결) 문제 데이터셋 (JSON 분리)
    └── storage.js      # 코인, 장착 스킨, 아빠 암호 해금 상태 localStorage 저장

```
