# 우주 블록 오락실 · UJU BLOCK ARCADE

8세 아이가 네 가지 블록 액션을 번갈아 즐기는 모바일 오락실. 긴 설명이나 문제지 화면 대신, 입체 캐릭터·즉각적인 반동·블록 폭발·합성 사운드로 플레이를 안내한다. 수 감각, 문장 어순, 작업기억과 충동 조절은 게임 규칙 안에 담고 게임 화면에 학습·평가 문구를 노출하지 않는다.

## 이번 구현 범위

이번 작업은 **공통 로비 + 모드 1 완성 + 모드 2**다. 모드 3·4와 실제 파츠 구매·PIN 상점은 다음 작업이다. 로비에는 네 카트리지를 표시하되 미구현 모드는 잠금 표시하며, 상단 아바타 버튼은 공통 아바타와 코인 보관함을 보여준다.

배틀은 **하늘 항구 3라운드**를 플레이할 수 있다. 각각 약 2~3분의 전투와 보스전 뒤 명시적으로 다음 무기를 선택한다. 8구역과 네 게임을 통한 2~4시간 이상의 콘텐츠는 후속 제작 목표이며, 현재 첫 구역의 약 7분 전투 분량과 구분한다.

| 라운드 | 새 경험 | 클리어 뒤 |
| --- | --- | --- |
| 1-1 선착장 돌격 | 기본 사격·연쇄 폭발, 철통 대장의 차선 공격 | 확산포 / 관통포 선택, 첫 보너스 40코인 |
| 1-2 화물선 추격 | 선택한 무기·이동 편대, 쌍둥이 집게의 좌우 공격 | 현재 무기 강화 / 연쇄포 선택, 첫 보너스 60코인 |
| 1-3 항구를 지켜라 | 무기 조합, 수호 거인의 중앙·차선 공격 | 항구 배지, 첫 보너스 100코인, 재도전 |

처음 세 라운드는 10 이내 연산과 같은 이동 속도를 유지한다. 구역 재도전부터 최근 안정된 선택 10회의 결과로 연산 범위를 10→20 이내로 조절한다. 입력 없이 통과하거나 통과 직전 차선을 바꾼 경우는 실력 판단 표본에서 제외한다. 무기 해금·강화·배지는 재도전과 재실행 뒤에도 유지되며 첫 보너스는 중복 지급하지 않는다.

| 모드 | 액션 | 게임 안의 규칙 | 순서 |
| --- | --- | --- | --- |
| 블록 계단 점프 | 빠른 두 버튼 점프, 탄성 착지와 콤보 | 0.5초 브레이크 예고 → 2초 멈추기, 50계단마다 상황 그림 다리 잇기 | 기존 연출 유지 + Phase 2 완성 |
| 3D 다리 배틀 런 | 붉은 현수교와 바다, 드래그 부대 이동, 자동 연사·배럴 폭발 | `7 + 8` / `19 − 2` 중 큰 결과 선택 → 그 숫자만큼 부대원 증가 → 보스 격파 | 신규 1순위, 이번 구현 |
| 슈퍼 블록 런 | 자동 횡스크롤, 점프 버튼 하나, 낱말 풍선 헤딩 | 누가 → 무엇을 → 어쨌다를 완성하면 5초 황금 거대화 | 다음 구현 |
| 3D 블록 광장 심부름 | 쿼터뷰 자유 이동, 목표 물건 수집·배달 | 그림·음성 미션을 기억하고 유혹 물건을 피하면 보물상자 | 다음 구현 |

## 실행과 조작

Node.js 20 이상. 런타임 패키지 설치 없이 실행한다.

```sh
npm run dev
```

컴퓨터는 `http://localhost:3000`, 같은 와이파이의 휴대폰은 `http://컴퓨터의-LAN-IP:3000`을 연다. 포트 변경: `npm run dev -- --port 3001`. 클라우드에서는 해당 환경이 제공하는 미리보기 주소를 사용한다.

- 로비: 카트리지를 터치한다. 아바타·코인 보관함은 상단 버튼으로 연다.
- 계단: 왼쪽은 방향 전환, 오른쪽은 오르기. 키보드 `←`/`Z`, `↑`/`→`/`X`/`Space`도 지원한다. 그림 다리는 아래 두 그림 중 하나를 고른다.
- 배틀 런: 다리 화면을 좌우로 드래그한다. 키보드 `←`/`A`, `→`/`D`도 지원한다. 사격과 전진은 자동이다. 클리어 화면에서는 무기 카드를 골라 다음 라운드로 이동하며 자동으로 다음 전투가 시작되지 않는다.
- 홈: 왼쪽 위 집 아이콘. 마지막 게임 입력 후 0.8초가 지나고 누르고 있는 손가락·키가 없을 때 활성화된다. 진행 중인 모드의 상태는 같은 실행 안에서 보존한다.
- 화면을 벗어나면 게임·소리·타이머를 멈춘다. 브레이크 중 복귀할 때는 노란 예고부터 다시 시작한다.

모든 모드는 720×1280, 중앙 9:16 FIT, 상하 최소 48 CSS px 안전 영역을 공유한다. 계단의 두 버튼은 하단 22% 전체를 입력 영역으로 쓴다. 배틀 런은 화면 드래그를 사용한다. 외부 이미지·음원·폰트·라이브러리는 요청하지 않는다.

## 공통 코인과 아바타

모든 게임은 공통 프로필에 코인을 지급한다. 장착 슬롯은 머리·몸통·등으로 나누며, 현재 기본 파일럿 아바타를 로비·계단·부대에 동일하게 적용한다. 파츠 구매와 PIN 해금 UI는 다음 단계다.

프로필은 버전이 있는 `localStorage`에 저장하며 기존 v1 코인·장착을 v2로 이전한다. 배틀의 라운드·적·탄·보상·선택한 무기·선택 대기 화면도 복원한다. 일반 진행은 1초마다, 보상·무기 선택·화면 이탈은 즉시 저장한다. 코인과 대응하는 전투 상태는 같은 문서에 함께 저장한다. 손상된 전투 데이터는 현재 라운드 시작으로 복구하며 정상 지갑과 해금을 유지한다. 계단 진행 위치는 새 실행에서 초기화한다.

저장이 차단되거나 용량이 부족하면 메모리로 계속 플레이하고 보관함에 상태를 표시한다. 브라우저 데이터 삭제·다른 기기로의 이전을 복구하는 클라우드 저장은 아직 없다. PWA 설치와 오프라인 파일 캐시는 후속 단계다.

## 판정 기본값

- 일반 계단 1코인, 10콤보마다 추가 5코인. 방향 실수는 1초 휘청임과 콤보 초기화만 적용한다.
- 브레이크는 15~25계단 간격. 노란색 500ms는 입력 허용, 빨간색 2,000ms는 게임 입력 시 실패. 성공 시 15코인과 5계단 자동 상승. 자동 상승에는 일반 계단·콤보 보상을 중복 지급하지 않는다.
- 50계단 그림 다리가 우선이다. 직전 3계단에서는 새 브레이크를 시작하지 않는다. 자동 상승이 50의 배수를 지나면 마지막 착지 뒤 그림 다리를 연다. 정답 보상 50코인은 한 번만 지급하고, 다른 그림을 골라도 다시 선택한다.
- 배틀 게이트는 결과가 서로 다른 두 수식이다. 첫 구역의 첫 도전은 피연산자·결과 10 이내, 결과 차이 최소 3이다. 재도전에서 단계적으로 20 이내와 비슷한 결과 비교를 연다. 좌우 위치와 문 색은 정답과 독립적이다. 큰 결과를 고르면 해당 수만큼 부대를 더하고 작은 결과는 현재 총원의 15%를 내림해 1~3명만 줄인다. 부대는 최소 1명을 유지한다.
- 부대 숫자는 실제 총원, 화면에는 최대 24명을 대표로 그린다. 총원에 따라 연사 탄수·피해량이 증가한다. 배럴·적군은 코인, 보스는 60코인. 보스 격파 후 다음 구간으로 이어지며 게임오버는 없다.
- 사격하면 피해 숫자·반동·두 단계 균열이 보이고, 위험 줄무늬 배럴은 주변 적까지 연쇄 폭발한다. 번개 무기 상자를 부수거나 적 4개를 격파하면 6초간 청록색 확산 연사로 바뀐다. 적은 가로 대열·폭발 배럴 호위·좌우 이동 편대로 등장한다.
- 보스는 부대의 기본 화력에 맞는 체력으로 등장한다. 라운드에 따라 1.5/1.4/1.3초 예고를 준 뒤 차선 또는 중앙을 내려친다. 안전한 쪽으로 피할 수 있고 맞아도 최대 2명만 줄어 최소 1명은 남는다. 체력 절반 아래에서는 공격 간격이 짧아진다. 백그라운드 복귀 시 공격 예고를 다시 충분히 보여준다.
- 한국어 기기 내 TTS가 있으면 상황 음성을 읽는다. 사용할 수 없거나 실패해도 그림과 상황별 합성 소리로 진행하며 외부 음성 파일을 요구하지 않는다.

수치 조정은 `js/config.js`, 구조와 완료 기준은 [PLAN.md](PLAN.md)를 따른다.

## GitHub Pages

**main 브랜치 루트 직접 서빙** 방식이다. `.nojekyll`, `index.html`, `css/`, `js/`를 그대로 제공한다. 별도 Actions 빌드나 `dist/` 업로드가 필요 없다.

[저장소 Pages 설정](https://github.com/choigoyoon/woojugame/settings/pages)에서 **Deploy from a branch → main → /(root)**를 선택하면 이후 main 푸시마다 재배포한다. 실행 주소: **[우주 블록 오락실](https://choigoyoon.github.io/woojugame/)**.

HTML과 모든 ES 모듈은 `./` 상대 경로를 사용한다. `npm run dev -- --base /woojugame/`로 같은 하위 경로를 로컬에서도 검증할 수 있다. `npm run build`는 별도로 `dist/index.html` 단일 파일을 생성한다. `dist/`와 `test-results/`는 Git에서 제외한다.

## 검증

```sh
npm test
python3 -m pip install -r requirements-browser.txt
python3 -m playwright install chromium
npm run test:browser
npm run test:visual
npm run test:campaign
python3 tests/battle_impact_check.py
python3 tests/browser_check.py --stress-seconds 180 --stress-hz 9
```

기존 Chromium을 쓰면 `CHROMIUM_PATH`로 경로를 지정한다. 자동 검증은 모바일 터치·해상도를 에뮬레이션하며 안드로이드 실기기 통과를 의미하지 않는다. 결과와 캡처는 `test-results/`에 생성한다. 최신 3라운드·진행 저장 결과는 [하늘 항구 검증 기록](docs/HARBOR_VALIDATION.md), 이전 통합 결과는 [오락실 검증 기록](docs/ARCADE_VALIDATION.md), 과거 계단 단독 결과는 [기존 기록](docs/PHASE1_VALIDATION.md)에 구분한다.
