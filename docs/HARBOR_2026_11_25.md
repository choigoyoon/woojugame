# 항구 배틀 실제 플레이 개편 — 2026년 11월 25일

이번 범위는 새 항구 배틀 세 구간, 구조 결과의 로비 반영, 재출동 선택이다. 기존 세 모드는 유지했다. 전체 STORY, 연령 설정, L0 전체, 상용 출시/다년 재미 검증 완료를 뜻하지 않는다.

## 플레이 변화

- 각 구간 지원병 수식 문은 18/50초 두 번만 등장한다. 작은 양수도 표시한 수만큼 합류한다. 중앙에 두면 큰 답을 대신 고르지 않는다. 첫 H1은 3명/5명, 7명/9명이다.
- 가로 대형, 세로 대형, 폭발물 호송대, 움직이는 적, 두 별 도장 상자, 예고된 차선 공격을 시간표로 배치했다. 단순 HP 증가로 재출동 차이를 대체하지 않는다.
- 보급 선택은 **지원병 5명 / 실드 2개**, **확산포 / 관통포**다. 탄환은 보급품을 파괴하지 않으며 직접 그 차선으로 들어가야 받는다. 한쪽을 받으면 반대쪽도 소진된다. 실드는 최대 4개이며 피격 후 1초 중복 충돌 방어를 적용한다.
- 집게 견인차가 기관차, 짐칸, 마지막 깃발 칸을 붙잡는다. 좌우 연결 볼트 둘을 조준해 풀어야 격파된다. 공격 직후 1.5초 취약 상태는 1.5배 피해다. 첫 구간의 첫 공격은 반대 차선이며 이후 예고된 차선은 플레이어를 따라 바뀌지 않는다.
- 구조 직후 기차의 귀환을 보여 주고, 다음 결과 화면에 짐칸 단서를 남긴다. 기차는 로비에 계속 보관되며 탭하면 경적을 울린다.
- 세 구간 완료 후 해금 무기와 두 선로를 선택한다. 화물 선로는 가로/세로 대형, 호송대/이동 적과 방향을 바꾼다. 2선로×3구간의 최고 기록·횟수·선택 메달을 저장한다. 메달은 연쇄 4, 상자 2, 보스 공격을 한 번 이상 겪고 피해 없이 완료다. 실드 방어도 무피해로 인정하며 메달 실패가 진행을 막지 않는다.

## 저장 계약

프로필 v4, 배틀 체크포인트 v2. v1/v2/v3 프로필의 코인·파츠·설정·무기·이전 기록을 보존한다. 기존 v1 전투 체크포인트는 적·탄환·시간·보스 HP·이전 등장 규칙을 유지하며, 다음 안전한 라운드 시작부터 새 항구 규칙을 사용한다. v2의 `mission:null`은 이전 규칙으로 진행 중임을 뜻한다. 새 판에는 보급 진행 위치, 실드, 연결 볼트, 수집, 메달 상태를 함께 저장한다.

보상·구조·적 소진·체크포인트는 프레임 계산 후 함께 저장한다. 이전 클리어 보너스를 재지급하지 않는다. 잘못된 미션 데이터나 실제 볼트 개수와 파괴 기록이 다른 상태는 해당 판만 복구하며 별도 코인·소유·구조 기록은 남긴다. 상위 저장 버전을 구버전이 덮어쓰지 않는 보호를 유지한다. 같은 브라우저의 백업 키는 독립 백업이 아니다.

## 프레임 계측

다른 무거운 검사와 분리해 실시간 Chromium, 412×915 CSS, DPR 2에서 모드당 약 25초 측정했다. 표시 프레임 기준 계단 **59.71**, 배틀 **59.83**, 러너 **59.92**, 광장 **59.97fps**. RAF 간격 p95는 16.7~16.8ms. 50ms 초과 작업은 계단 1건(65ms), 러너 1건(51ms), 배틀/광장 0건으로 기록했다. 평균 통과를 모든 프레임 무지연으로 표현하지 않는다.

별도 강제 래스터 readback 부하 검사 150프레임에서 새 보스 평균 **12.31ms**, p95 **17.70ms**, 일반 배틀 평균 11.49ms를 기록했다. 이는 디스플레이 FPS 검사가 아니며 Android의 16.67ms 예산 충족을 보장하지 않는다. 실제 기기별 계측과 열화 조건 검증은 남아 있다.

## 배포와 남은 일

GitHub Pages는 `main` 루트를 직접 서빙한다. `dist` 업로드 방식이 아니다. `npm run build`가 앱 셸 캐시를 갱신하며 Actions는 검증을 실행한다. 이번에는 세 구간 실제 터치 완주 검사도 CI에 추가했다.

Android 실기기 60fps/발열/터치, 8세의 목적 이해·다른 무기 자발적 선택·다음 날 재방문은 미검증이다. 상용 출시 판단은 이 관찰 뒤에 한다. 연령/축별 설정, 나머지 모드의 액션 중심 재설계, STORY 전체의 원인·단서·결과, 계단 이어하기와 독립 백업은 별도 작업으로 남는다. 몇 년 동안의 고유 콘텐츠를 확보했다고 주장하지 않는다.
